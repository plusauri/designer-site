pictogrammes de catégorie fiscale

Tutilis

Les petits symboles que le produit place devant le nom d'un compte pour que son traitement fiscal se lise d'un coup d'œil : 🧾 imposable, 🛡️ traditionnel / à imposition différée, 💎 Roth. Les actifs réels restent 🏠 et les prêts immobiliers portent le symbole de prêt. La même décoration apparaît dans Vue d'ensemble et dans le Détail de prévision, si bien qu'une seule habitude sert partout. C'est une décoration, pas un code fiscal — l'idée sous-jacente est la catégorie fiscale.

Où le trouver dans l'application

Où le saisir

  • Chaque type de compte porte ici sa marque, et le pied du menu explique les trois.

Où il apparaît dans la prévision

  • Une marque par compte sur chaque ligne ; survolez son Solde final pour afficher la fiche du compte.
