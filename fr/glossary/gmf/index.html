GMF ✦

Tutilis

GMF ✦ (aussi FID 0 / GMF) est l'étoile polaire du produit — la trajectoire de prévision déterministe à moyenne géométrique qui vous sert de cap, et non un tirage Monte Carlo aléatoire ni le scénario « le plus probable ». Privilégiez-la pour une lecture stable, année par année, du plan. Changez-en lorsque vous voulez explorer d'autres scénarios ou trajectoires aléatoires dans le nuage multi-trajectoires. Le symbole ✦ correspond à la commande FID en direct (boussole / étoile polaire, pas une étoile de notation).

Où le trouver dans l'application

Où il apparaît dans la prévision

  • Le FID 0 est la trajectoire GMF, celle sur laquelle s'ouvre le Détail de prévision.
