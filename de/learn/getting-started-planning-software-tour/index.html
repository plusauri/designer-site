Wo es in der Prognose erscheint

Lesen Sie die Streuung. Achten Sie mehr auf die Richtung, in die eine Änderung die Erfolgsquote schiebt, als auf den Prozentsatz selbst.

  1. Öffnen Sie Änderungen.
  2. Wählen Sie etwas unter Änderbare, oft eine Person oder einen Cashflow-Posten wie Erwerbseinkommen.
  3. Bearbeiten Sie eine Steuerung: Ruhestandsjahr, aktive Jahre, Ausgaben. Das Bearbeiten ist das Hinzufügen zum Änderungssatz. Es gibt keinen eigenen Schritt zum Hinzufügen.
  4. Diagramme und Tabellen aktualisieren sich live, sodass Sie den Plan reagieren sehen, bevor eine neue Simulation läuft.
  5. Neu simulieren, wenn Sie den vollen Vergleich von Original und geändertem Plan wollen.
