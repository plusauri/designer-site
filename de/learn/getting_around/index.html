Eine zweite brauchen Sie nicht. Das Erscheinungsbild ist nur eine Präferenz; es ändert die Planrechnung nicht.

Kontextsensitive Tooltips — und wann man sie dämpft

Um möglichst viel Detail ohne überfülltes Layout zu zeigen, setzen wir stark auf kontextsensitive Tooltips. Viele erscheinen, wenn Sie Diagramme, Tabellen, Zeilen und andere Steuerungen überfahren; ein großer Teil dieser Tipps ist ebenfalls kopierbar. Manche Diagramm- und Tabellenregionen existieren vor allem, damit Hover dieses Detail zeigen kann.

Suchen Sie nach — dem ? auf vielen Panel- und Kartentiteln. Öffnen Sie es für eine kurze Erklärung dieser Oberfläche. Hover steuert weiterhin die kleineren Tipps auf einzelnen Zeilen, Balken und Punkten.

Diese Aggressivität ist großartig, wenn Sie eine Oberfläche lernen. Sie kann stören, wenn Sie präsentieren — jemanden durch einen Pfad führen und die Popups feuern weiter, während der Zeiger sich bewegt.

Halten Sie Alt gedrückt, während Sie mit der Maus über diese Steuerungen fahren: Mit der Standardeinstellung erscheinen Tooltips nicht, solange Alt unten ist. Das ist die schnelle, vorübergehende Stille für eine Demo oder einen sorgfältigen Klick.

Wenn Ihnen der Standard immer noch zu gesprächig ist, kehren Sie die globale Regel um. Neben der Hell/Dunkel-Theme-Steuerung sitzt ein kleiner gefüllter / hohler Kreis (Hover-Details). Klicken Sie ihn, um den Modus umzuschalten:

Also: Standard ist „hilf mir, es sei denn, ich halte Alt.“ Umgekehrt ist „lass mich in Ruhe, es sei denn, ich halte Alt.“ Wählen Sie den Modus, der passt, ob Sie erkunden oder präsentieren; Alt gibt Ihnen immer das Gegenteil mit einer Geste.

Schnellsprünge zu den Key Forecasts

Unter dem Label Forecast ID liegt eine kleine goldene Linie mit einer Reihe von Marken. Das sind Schnellsprünge: Klicken Sie eine und die Forecast ID landet auf dieser Prognose.

Jedes farbige Dreieck ist eine der Key Forecasts des Laufs, in derselben Farbe gezeichnet, die diese Prognose in der Key-Forecasts-Tabelle und in der Verteilungswolke hat — also ist Rot überall Min. Hover über eines, um zu sehen, welche Prognose es ist, ihre ID und was der Punkt bedeutet.

Zwei Dinge über diesen Streifen lohnen Verständnis, weil sie beabsichtigt sind:

  • Die Marken lesen schlechtestes Ergebnis → bestes, von links nach rechts — Min, Q2, GMF ✦, Q3, Mean, Q4, Max, dieselbe Reihenfolge wie die Zeilen der Key-Forecasts-Tabelle. Das goldene ✦ ist der deterministische Nordstern in dieser Ordnung, damit Sie sehen, wo die GMF unter den benannten Outcomes sitzt — nicht seitlich abgestellt.
  • Sie sind nicht an ihren Forecast-IDs positioniert. Eine Forecast ID ist ein Name, keine Messung: Der Lauf kann seinen schlechtesten Pfad auf ID 366 und seinen besten auf ID 12 landen, und das sagt Ihnen nichts über beides. Also nutzt der Streifen seine Breite für die Ordnung, die etwas bedeutet. (Die Dreiecke des Year-Sliders sind der umgekehrte Fall — ein Jahr ist eine Position, also sitzen sie genau dort, wo sie auf der Timeline fallen.)

Bevor Sie eine Simulation laufen gelassen haben, gibt es nur das ✦ zum Springen, was ehrlich ist: Es gibt noch keine anderen Prognosen. Lassen Sie eine laufen und der volle Streifen erscheint.
