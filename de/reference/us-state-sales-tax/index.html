Where we use this · Not used yet

  • Nothing in the forecast assesses sales tax. There is no modeled consumption basket to apply a rate to, so applying one would mean inventing a spending pattern.
  • It is shown here and in the US States comparison as context for a relocation, and nowhere else.

Not modeled

The forecast does **not** assess sales tax anywhere. This is captured for reference only: no consumption model exists to apply a rate to, so adding one to the projection would be inventing a spending pattern rather than measuring one.
