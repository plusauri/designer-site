FID

Tutilis

Forecast ID (Prognose-ID) – welchen der simulierten Pfade Sie gerade betrachten. Eine Simulation berechnet viele Pfade; das FID-Steuerelement wählt einen aus, damit die Jahr-für-Jahr-Diagramme und -Tabellen eine einzige Geschichte erzählen. FID 0 ist der deterministische GMF ✦-Leitsternpfad statt einer zufälligen Ziehung.
